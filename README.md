# SoeYaku

Mac の「プレビュー」で英語の PDF を読みながら、隣のウインドウで日本語訳を読むためのローカル翻訳ツールです。PDF の本文全体を先に PLaMo 3 Translate で訳して保存し、プレビューでポインターを置いた文の訳を訳文ウインドウで強調して、その位置までスクロールします。翻訳と文字認識は Mac の中で行い、訳文は元のアプリの上には描きません。

講演を聴く用途には [Kikiyaku](https://github.com/utahta/kikiyaku) を使い、SoeYaku は配布資料などの文書を読む側を担います。両者は用語集の形式（`原語 = 訳語`）を揃えています。

## 最初の訳を読む

Apple Silicon、macOS 26 以降、Swift 6.2 以降を含む Xcode、Homebrew 版の llama.cpp、Apple Development 署名を使います。

1. [モデルの準備](docs/model.md) に従って PLaMo 3 Translate 2B の GGUF を `local/models/` に置きます。
2. リポジトリのルートでアプリを作って開きます。画面収録の許可をアプリに結び付けておくため、ビルドには固定の署名を使います。

   ```sh
   Scripts/build-app.sh
   open dist/SoeYaku.app
   ```

3. 「PDF を開く…」でテキスト層のある英語の PDF を選び、「プレビューで開く」を押します。
4. 「全文を翻訳」を押します。訳した文から順に保存されるので、途中で中断しても次回は続きから訳します。翻訳サーバーはアプリが自動で開始・終了します。
5. 「プレビューに追従」を押し、プレビューで読みたい文にポインターを置きます。初回は「画面とシステムオーディオの録音」の許可を求められます。許可したら SoeYaku を開き直し、もう一度押してください。訳文ウインドウでその文の訳が強調され、スクロールやページ移動に合わせて移ります。

追従するのはプレビューが最前面で、ポインターがその最前面ウインドウの中にあるときだけです。ポインターを訳文ウインドウへ移すと、訳文を自由にスクロールできます。プレビューに戻すと追従を再開します。現在地を特定できないときは訳文ウインドウを動かさず、下端に「現在地を特定できません」と出します。

## 用語集

共通の用語集と文書ごとの用語集を「共通の用語集…」「この文書の用語集…」でテキストエディタで開けます。1行に `原語 = 訳語`（Kikiyaku と同じ形式）または `原語<TAB>訳語` を書きます。文書の用語集が共通の用語集より優先され、英語の大文字と小文字は区別しません。用語集を変えたあと「全文を翻訳」を押すと、その用語を含む文だけを訳し直します。

「Kikiyaku 用にコピー」は、この文書に出現する用語だけを `原語 = 訳語` の1行1組でクリップボードに入れます。Kikiyaku の用語集欄にそのまま貼れます。

## 保存するもの

`~/Library/Application Support/SoeYaku/` に共通の用語集を、その下の `Documents/<PDF の SHA-256>/` に文書の用語集と訳文を保存します。訳文は原文・その文に適用した用語・モデルの組で引くので、同じ箇所に戻ると同じ訳が出ます。画面の画像と認識した文字は現在地を探すためにだけメモリ上で使い、保存しません。

## 実装範囲

PDF のドキュメントモードを実装しています。二段組みは座標から左段→右段の読み順に並べ、ページ上下端の繰り返すヘッダーとページ番号を本文から除きます。現在地は、ポインターの下の行とその上下の行を Vision で読み、事前に抽出した本文の3語連続と照合して決めます。同じ見出しが何度も出る場合は前後の行で区別し、それでも決まらなければ直前の現在地に近い方を選びます。

HTML の文書、縦横比を自由に選ぶ枠モード1、縦横比を固定した枠モード2は未実装です。プレビューでの前進・逆スクロール・ページ飛びの実機確認と、正解の段落を付けた採点も未実施です。複数の段落が見えているときの現在地はポインター直下の文としましたが、採点方法とあわせて未決です。
